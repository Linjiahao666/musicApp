# Foundation

规格：[Spec: 跨平台音乐播放器 v1](https://github.com/Linjiahao666/musicApp/issues/15)

术语：仓库根目录 `CONTEXT.md`。使用 Song、Artist、Album、Cover、Lyrics、Manifest、Queue、Favorites、SyncState，避免 Track、Playlist、清单。

## 测试缝

只打 **LibrarySession**。三个端口：StoreFiles、LocalDisk、AudioEngine。用假实现测行为，不测 widget / 真实 HTTP / just_audio 内部。

## 架构红线

- Flutter 单仓，Android + Windows
- 一个函数只做一件事；少参数；不要过度封装
- UI 文案直接中文，不要 i18n key
- 禁止 any（Dart 里禁止滥用 dynamic 当 any）
- 不要提交 git
- 不要跑 build / analyze / test（主 Agent 收尾再跑）
